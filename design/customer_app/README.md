# UNIQUE BASKET Customer App Design References

This directory contains design references used during UNIQUE BASKET customer application development.

## Structure

### figma/

Figma exports, design references, or Figma-related documentation.

### references/

Visual references, screenshots, inspiration, specifications, and supporting design material.

### assets/

Design-source assets grouped by type.

### screens/

Screen-specific design references.

Each screen should have its own directory.

Example:

screens/
└── splash/
    ├── splash-spec.md
    └── assets/

## Important

Files inside this directory are primarily design/reference materials.

They should not automatically be treated as Flutter runtime assets.

Approved assets required by the Flutter application should be copied into:

apps/customer_app/assets/

only when the corresponding screen is implemented.
